# DS4002_CS3

This repository contains the study, deliverable, data, and reference materials necessary to complete the Case Study.

## Important Information

The two attached PDFs include all the instructions necessary for this case study, including the rubric, details on the deliverable, and some references that may be useful.

## Data

For this assignment, follow this link here: https://astronn.readthedocs.io/en/latest/galaxy10.html#download-galaxy10-decals to download the data. Alternatively, follow the code in the starter notebook to download the data via Python. Either way works.
Due to the size of this file, it cannot be uploaded into this repository.

## Reference Materials

See CS3 - Hook Document.pdf for references that could be of use to this case study. It contains tips on creating amodel from the people who created the dataset in this case study, a list of pytorch models that you can optionally use, and some extra context about the Nancy Grace Roman Space Telescope and galaxy types.

## Starter Code

Under the starter code folder, you will see a JupyterNotebook containing some introductory code creating a basic model for classification provided by the creators of this dataset. You may use this as a basis to learn how to load the file, split into training and test sets, and see how a simple neural net works.
